# Pirate Survivor

Mini-juego estilo **bullet-hell cooperativo de supervivencia**, inspirado en el ritmo de *Realm of the Mad God* pero con temática naval.

## Cómo jugar

1. Abre `index.html` en tu navegador.
2. Controles:
   - `WASD` o flechas para mover el barco.
   - Click sostenido o `espacio` para disparar.
3. Sobrevive a las olas, recoge botines y sube de nivel para mejorar estadísticas.

## Objetivo

Resistir hasta completar la ola 10 para lograr la victoria.
